# Modelos GLB/GLTF no Avatar Studio

Esta versão aceita modelos 3D externos em formato `.glb` ou `.gltf` por URL HTTPS.

## Modelos de demonstração

- **Cesium Man** — Khronos glTF Sample Assets. Crédito: © 2017 Cesium. CC BY 4.0, com limitações de marca descritas pelo repositório de origem.
- **Fox** — Khronos glTF Sample Assets. Modelo original CC0; rig e conversão com créditos CC BY 4.0 descritos pelo repositório de origem.

Os modelos são carregados do CDN jsDelivr apontando para o repositório oficial KhronosGroup/glTF-Sample-Assets. Eles servem como demonstração técnica do carregador, animações, texturas, iluminação e escala automática.

## Uso em produção

Para aparência premium ou fotorrealista, substitua a URL por um modelo criado ou licenciado para o Randers'CRM. O administrador é responsável por confirmar os direitos de uso e atribuição. O sistema mantém um avatar procedural como fallback caso o arquivo externo falhe.
